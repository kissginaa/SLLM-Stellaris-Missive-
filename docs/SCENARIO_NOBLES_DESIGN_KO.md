# 시나리오 「회랑의 삼파전」 — 귀족·충성도·인연·접견실 설계 (2026-11-06)

다른 세션이 이어 받을 수 있게 정한 것만 적는다. 구현 전 설계 문서.

## 0. 큰 원칙 (사용자 결정)

- **SLLM 본편은 시나리오 모드의 필수 의존성**이다(`descriptor.mod`의 dependencies에 `"SLLM Missive"`).
- **계산과 갱신은 거의 전부 앱에서 한다.** 게임 스크립트는 두 가지만 맡는다.
  - 정보 보고: 이미 있는 매달 섹터 보고 `SCNSEC`와 세이브 파일.
  - 실제로 일 일으키기: 반란, 귀순, 되돌려 앉히기, 작은 수정자. 앱이 콘솔 `effect …`로 부를 때만 돈다.
- 게임 쪽 월간 스크립트는 섹터 보고 하나뿐이다. 귀족 자리 지키기도 앱이 어긋남을 볼 때만 `effect sllm_cr_noble_keep = yes`로 부른다(구현 끝남).
- 모든 화면과 문구는 한/영을 함께 만들고(`L(한, 영)`), 언어 팩과 호환되게 한다.

## 1. 귀족 (구현 끝남, 게임 확인 전)

- **거점 63곳에 귀족 한 명씩** 둔다(A 28, B 35). 파라곤형 지도자다.
  - 고정: 이름, 성별, 초상화, 이벤트 지도자, 수명 +800, 거점 특화 고유 특성.
  - 표: `tools/gen_nobles.py` → `tools/nobles.json`, `common/scripted_effects/sllm_cr_nobles.txt`, 현지화 `sllm_cr_nobles_l_*`.
  - 초상화: 게임은 `gfx/models/portraits/sllm_cr/sllm_cr_noble_<a|b>_<번호>.dds`, 앱은 `ui/assets/scenario/corridor/gov/gov_<A|B>-<번호>.png`.
- **거점 행성 = 섹터 수도, 귀족 = 그 섹터 총독.**
  - 일반 섹터 범위를 2칸으로 줄였다(`common/sector_types/01_other.txt`). 이걸로 거점마다 섹터가 하나씩 생긴다.
  - 수도 곁 4곳(A 342·396·561, B 263)은 수도 섹터에 들어간다. 이 귀족들은 나중에 지도자용으로 쓴다.
- **얼라이언스 종족 섞기**: 인간, Velari, 새 9종족(rep, art, mol, fun, mam, lith, plant, necro, aqua)을 섞는다. 귀족은 자기 그림 부류의 종족으로 만든다.

## 2. 충성도 (나라에 대한 마음, 0~100)

- **시작값**
  - 기본은 100.
  - **국경 거점**(진영 땅 가장자리, 회랑 쪽에서 8칸 이내)만 70~80. 세이브마다 한 번 무작위로 정한다.
    - A: 504, 511, 357, 456, 541, 344, 495, 459
    - B: 63, 305, 156, 105, 199, 297, 114, 130
- **계산 시점**: 앱이 매달 섹터 보고를 받을 때, **분기(3달)마다 한 번**. 앱이 꺼져 있던 기간은 따라잡지 않는다.
- **성격 5가지 (배너로드식)**: 명예, 자비, 관대, 용맹, 계산을 각각 −2~+2로 귀족마다 고정한다(표로 미리 지정). 사건에 대한 반응 크기와 방향을 정한다.
- **원인 (분기마다, 초안)**

  | 원인 | 변화 |
  |---|---|
  | 기준값 쪽으로 천천히 돌아감 | ±1 |
  | 자기 섹터 점령 또는 거점 상실 | −6 |
  | 전쟁에서 지는 중 | −3 |
  | 전쟁에서 이김 | +3 |
  | 긴장도 동원 단계 이상 | A −1, B +1 |
  | 회유 계략 | −5 ~ −15 |
  | 소속국의 달래기·은상 | +5 ~ +10 |
  | 소속 통치자와의 친밀도 | 단계별 가감 |
  | 인연 연쇄 (6절) | 종류별 가감 |

  섹터 안정도는 세이브에 값이 있으면 넣는다.
- **단계**

  | 충성도 | 단계 |
  |---|---|
  | 70+ | 충성 |
  | 40~69 | 평온 |
  | 25~39 | 불만 (신문에 소문) |
  | 10~24 | 모반의 기미 (경고, 소속국 AI가 달래기 시도) |
  | 0~9 | 반란 직전 (분기마다 확률로 반란 또는 귀순) |

## 3. 반란과 귀순 (게임 효과, 앱이 부름)

- **반란**: `effect sllm_cr_noble_revolt = { N = <거점 번호> }`
  1. 거점 행성에서 `create_rebels`로 반란국을 만든다.
  2. 같은 섹터의 행성과 정거장을 `set_owner`로 넘긴다(`sector = { every_system_within_border }`).
  3. 귀족을 반란국 통치자로 세운다(`exile_leader_as` → `set_leader`). 국명은 「○○ 가문령」.
  4. 원래 나라와 독립 전쟁을 건다(`declare_war`).
  5. 앱이 이어 받는다: 본편 반란국 기능(부모 제국 기억), 신문 호외, 연대기.
- **귀순**: 충성도가 바닥이고 플레이어와 친밀도가 높으면, 반란 대신 **섹터째 플레이어 나라로** 넘어온다. 같은 효과에서 받는 나라만 플레이어로 바꾼다. 상대 거대 세력으로 넘어가는 경우도 성격에 따라 가능하다.

## 4. 친밀도와 인연 (사람 대 사람)

- **사람 사이의 수치**다. 범위는 귀족 ↔ 소속 통치자, 귀족 ↔ 플레이어 통치자, **귀족 ↔ 귀족**.
- **단계 이름 (스텔라리스식, 한/영)**
  - 좋은 쪽: 접촉 Contact → 우호 Cordial → 신뢰 Trusted → 협약 Accord → 서약 Oathbound
  - 따로: 혼약 Union
  - 나쁜 쪽: 냉담 Cold → 경쟁자 Rival → 숙적 Nemesis
  - 진영을 넘는 몰래 연락선: 비밀 회선 Back Channel
- **초기 인연표는 고정**한다(판마다 같음, `gen_nobles.py`에 넣음).
  - 같은 진영 안: 서약 8쌍, 혼약 6쌍, 협약 12쌍, 경쟁자 10쌍
  - 진영을 넘는 비밀 회선: 6쌍
- **올리는 수단**: 서신, 선물(백화점), 관저 파티와 만찬 초대, 접견실 1:1 대화. 모두 본편에 이미 있는 기능과 이어 붙인다.
- **연쇄**: 인연으로 엮인 귀족이 반란하거나 귀순하면, 서약과 협약은 따라 흔들리고 경쟁자와 숙적은 오히려 충성이 오른다.

## 5. 계략 (첩보 화면 안)

- 회유: 상대 귀족의 충성도를 낮추고, 나와의 친밀도를 올린다.
- 이간: 귀족과 그 통치자, 또는 귀족끼리의 친밀도를 떨어뜨린다.
- 유언비어: 신문과 인터넷으로 퍼뜨린다.
- 비용은 영향력. 성공률은 첩보 수준에 따른다. 들키면 관계가 나빠지고 긴장도가 오른다.

## 6. 공개 범위 (사용자 결정: 숨김)

- 처음부터 보이는 것: 혼약, 공식 경쟁자, 각 귀족의 충성도 **단계**.
- 알아내야 보이는 것: 서약, 협약, 비밀 회선, 정확한 충성도 숫자. 첩보 수준이나 접견실 대화로 알아낸다.

## 7. 화면

- **접견실 (본편 공용 엔진, 우선 시나리오 귀족만 사용)**
  - 전체화면 1인칭 배경에 상대 초상화를 크게 띄운다. 대화창, 친밀도 막대와 단계, 행동 버튼(대화, 선물, 술자리, 초대), 대화 기억.
  - 시나리오가 끼워 넣는 자리: 행동 버튼(회유, 이간, 귀순 제안), 상단 상태 줄(충성도 단계, 성격), 프롬프트 덧붙이기(`scenarioForPrompt` 방식).
  - 배경 그림은 GPT가 그린다. 3장: A 귀족 궁정 응접실, B 귀족 집무실, 플레이어 관저 응접실. 화면 가운데는 비우고, 아래 4분의 1은 대화창 자리.
- **인물 관계도 (본편 앱에 넣고, 시나리오 판에서만 열리게 잠금)**
  - 왼쪽 A, 오른쪽 B, 위쪽 가운데 플레이어.
  - 점 = 통치자 3명 + 귀족 63명. 원 초상화에 충성도 단계를 테두리 색으로 표시한다.
  - 선 색: 서약 금색, 혼약 분홍, 협약 초록, 신뢰 파랑, 경쟁자·숙적 빨강, 비밀 회선 점선.
  - 인물을 누르면 상세 정보와 「접견」 버튼. 필터는 진영, 인연 종류, 내가 아는 것만.
  - 여는 곳: 시나리오 은하 지도, 접견실.
