# 「회랑의 삼파전」 은하 지도 빛 그림 의뢰서 — 2026-11-07

은하 지도(게임의 전체 지도 화면) 바닥에 깔리는 **은하의 빛과 성운** 그림을 부탁드립니다.
게임은 이 그림을 은하 평면에 눕혀 깔고, 그 위에 별·항로·국경을 그립니다. 그래서 별 하나하나는 그리지 않고 빛과 구름만 그립니다.
섹터 경계선과 지역 이름은 제가 따로 좌표로 그려서 겹칩니다. 이 그림에는 넣지 않습니다.

## 꼭 맞춰야 할 배치
- 첨부 `sllm_cr_galaxy_layout_reference.png`(4096×4096)가 실제 지도 배치입니다.
  - 빨간 점: 인류 제국 성계(왼쪽 덩어리)
  - 파란 점: 은하 얼라이언스 성계(오른쪽 덩어리)
  - 흰 점: 두 세력을 잇는 위·아래 두 회랑(위는 세렌 회랑, 아래는 바스틸 회랑)
  - 노란 점: 플레이어 나라(세렌 회랑 가운데)
  - 회색 선: 항로
- **같은 4096×4096 캔버스에서 위치·크기·비율을 정확히 그대로** 지켜 주세요. 빛이 성계 덩어리 위에 정확히 얹혀야 합니다.
- 가운데 비어 있는 큰 타원은 성계가 없는 공허입니다. 거의 검게 두고, 아주 희미한 먼지 고리 정도만 둡니다.
- 캔버스 바깥쪽 여백(위·아래 큰 검은 부분)은 아주 엷은 먼지가 사라지듯 페이드되게 그립니다.

## 그림 내용
| 영역 | 빛의 느낌 |
|---|---|
| 인류 제국(왼쪽) | 진홍·잿불 색 성운, 짙은 붉은 먼지구름, 군데군데 철빛 회색 띠. 차갑고 위압적이게 |
| 은하 얼라이언스(오른쪽) | 청백·하늘색 성운, 은빛 먼지, 군데군데 금빛 반짝임. 맑고 넓게 |
| 세렌 회랑(위) | 두 색이 만나는 좁은 강. 은은한 금빛·호박색 별빛의 흐름, 가운데(플레이어 자리)가 살짝 더 밝음 |
| 바스틸 회랑(아래) | 옛 전쟁터. 탁한 회색·주황 먼지, 꺼져 가는 불씨처럼 어둡게 |
| 가운데 공허 | 거의 검정, 아주 희미한 먼지 고리 |

## 규격 (중요)
- **배경은 완전한 검정(#000000)**입니다. 게임은 이 그림을 「더하기」로 겹쳐서 검정은 투명이 됩니다. 투명 PNG가 아니라 검정 배경 RGB로 주세요.
- 밝기는 은은하게 합니다. 가장 밝은 곳도 흰색까지 가지 말고 60% 안팎으로 해 주세요. 위에 별·국경·글자가 얹혀도 읽혀야 합니다.
- 글자, 문장, 실존 상징은 넣지 않습니다. 별을 점으로 또렷하게 찍지 않습니다(자잘한 별가루 반짝임은 괜찮음).
- 파일은 두 장입니다.
  1. `sllm_cr_galaxy_glow.png`, 4096×4096: 위 내용 전체를 담은 본 그림입니다.
  2. `sllm_cr_galaxy_dust.png`, 4096×4096: 같은 배치의 **가는 별가루·미세 먼지만** 담은 겹입니다. 본 그림보다 더 어둡게 해 주세요. 높이를 조금 달리 깔아 입체감을 줍니다.
