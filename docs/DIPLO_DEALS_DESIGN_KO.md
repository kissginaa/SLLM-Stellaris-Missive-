# 외교 거래 설계서 — 설득 확률·묶음 거래·조공 평화·갈고리·참전 요청 (2026-10-26, 다음 업데이트)

CK3·배너로드에서 가져온 다섯 가지. 공통 원칙: **말로 한 약속이 게임 수치로 남는다**, 결과는 앱이 정하고 AI 는 말만 한다(추가 LLM 호출 없음), 수치는 게임에서 다시 확인한 값만 믿는다.

## 1. 확정 사항 (사용자 2026-10-26)
| 항목 | 결정 |
| --- | --- |
| ① 설득 확률 | 수락·거절은 **앱 주사위**가 정한다. 확률을 먼저 보여 주고, AI 는 결과에 맞춰 말한다 |
| 확률 재료 | 호감(의견 점수)·신뢰·국력 차이·거래 저울 |
| ② 묶음 거래 항목 | 자원(한 번에)·자원(매달 N개월)·국경 개방·경쟁 관계 해제·약속(불가침·참전 등) |
| ③ 조공 평화 | 매달 지급 한도 = 내는 쪽 그 자원 월수입의 20%, 최대 10년(120개월) |
| ④ 갈고리 얻기 | 첩보 보고서에서 **확인된 비밀**(소문 아님)을 찾으면 |
| 갈고리 힘 | 쓰면 수락 확률 +30%p, 한 번 쓰면 사라짐 |
| ⑤ 참전 요청 거절 | 요청한 쪽의 호감 -30 + 신문 보도 |
| 우리가 약속을 어기면 | 상대 호감 -50 + 신문 보도 + 상대가 우리에 대한 갈고리를 얻음 |

## 2. 흐름
1. 여는 곳 두 군데(2026-10-26 사용자 확정 — 집무실 인터페이스를 따른다):
   - **집무실 바탕화면 「국정」의 「외교 거래」 아이콘**(대사관 다음). 대사관 화면과 같은 틀: 왼쪽 = 통신 중인 일반 제국 목록(호감·전쟁 중·경쟁국·갈고리·우리가 빚짐·약속 수) + 동맹의 참전 요청, 오른쪽 = 고른 제국과의 거래판. 통신을 열지 않고도 제안할 수 있고, 이때는 **AI 를 부르지 않고** 결과만 보인다(호감은 연락처 목록의 의견 점수).
   - 외교 단말기에서 통신 중일 때 입력줄 옆 **「거래 제안」** 버튼(단말기 서랍과 같은 틀). 이때만 상대 AI 가 결과에 맞춰 한마디 한다.
   거래판: 왼쪽 = 우리가 주는 것, 오른쪽 = 받는 것.
2. 항목을 담을 때마다 앱이 **저울**과 **수락 확률**을 바로 보여 준다(게임에서 한 번 읽어 둔 값으로 계산, 추가 호출 없음).
3. 「제안하기」 → 앱이 주사위를 굴린다 → 통신 중이면 결과(수락/거절)를 AI 에게 알려 주고, AI 는 그 결과에 맞는 한두 문장만 말한다(평소 대화 한 번과 같은 호출). 집무실 목록에서 연 거래는 호출 없음.
4. 수락이면 게임 효과를 바로 걸고(자원·국경·경쟁 해제·종전·참전), 매달 지급·약속은 앱이 기록하고 매달 지켜본다.
5. 같은 상대에게 같은 달에 다시 제안하면 확률 -10%p 씩(조르기 방지, CK3 의 「최근 거절」).

## 3. 확률 공식 (사용자 확정 2026-10-26)
`확률 = 50 + 호감 + 신뢰 + 국력 + 저울 + 갈고리 (+ 동맹 + 전쟁 피로)`, 5%~95% 로 자른다.
| 재료 | 계산 | 범위 |
| --- | --- | --- |
| 호감 | 상대 의견 점수 ÷ 4 | -25 ~ +25 |
| 신뢰 | 게임 신뢰 구간 0~4 (0,10,30,60,90 기준) → -5, 0, +5, +10, +15 | -5 ~ +15 |
| 국력 | 우리 종합 국력이 상대에 비해 한심~압도 → -14, -7, 0, +7, +14 | -14 ~ +14 |
| 저울 | (상대가 받는 가치 - 상대가 주는 가치) ÷ 기준 × 50. 기준 = max(500, 상대 에너지 월수입 × 12) | -60 ~ +30 |
| 갈고리 | 쓰면 | +30 |
| 동맹 | 참전 요청을 방위 조약·연방 상대에게 할 때 | +25 |
| 전쟁 피로 | 종전이 든 거래: (상대 진영 피로 - 우리 진영 피로) × 60 | -60 ~ +60 |
| 다시 조르기 | 같은 달 같은 상대에게 두 번째부터 | -10 씩 |

## 4. 가치표 (사용자 확정 2026-10-26)
가치 단위 = 에너지. 자원은 바닐라 시장 기본 가격과 같은 비율. **외교 항목(국경·경쟁 해제·불가침·참전)은 연도 배율**: 2250년 전 ×1, 2300년 전 ×2, 그 뒤 ×3(그레이트 칸 선물·퀘스트 자원과 같은 questYearFactor).
| 항목 | 가치 |
| --- | --- |
| 에너지·광물·식량 1개 | 1 |
| 소비재 1개 | 2 |
| 합금 1개 | 4 |
| 매달 지급 | 한 달 가치 × 개월 수(할인 없음) |
| 국경 개방(상대가 열어 줌) | 150 |
| 경쟁 관계 해제(상대가 우리를 경쟁국에서 뺌) | 500 |
| 불가침 약속 1년(한쪽이 상대를 공격하지 않음) | 100 × 년 |
| 참전(상대가 우리 전쟁에 들어옴) | 2000 |
| 종전 | 0(대신 전쟁 피로가 확률에 들어감) |

- 한 번에 주는 자원은 지금 창고 이하, 매달 지급은 내는 쪽 월수입 20% 이하·최대 120개월.
- 상대가 우리에게 주는 쪽도 같은 표(상대 창고·수입은 거래판을 열 때 게임에서 읽음).

## 5. 약속·매달 지급 감시
- 매달 지급: 앱이 매달 게임에 이전 명령을 보낸다(모드가 창고를 확인하고 옮김). 내는 쪽 창고가 모자라면 그달은 「미납」, **두 달 연속 미납이면 약속 파기**(사용자 확정).
- 불가침 약속: 매달 전쟁 목록을 보고, 약속한 쪽이 공격자로 전쟁을 시작했으면 파기.
- 참전 약속: 상대가 「다음에 우리 전쟁이 나면 참전」을 약속한 경우, 우리 전쟁이 시작될 때 앱이 참전을 요청하고 거절하면 파기.
- **우리가 어기면**: 상대 호감 -50(의견 수정자, 서서히 회복) + 신문 보도 + 상대가 우리에 대한 갈고리 1개.
- **상대가 어기면**: 연대기·신문 보도. 남은 지급은 멈춘다(우리가 받을 것). 갈고리는 첩보 비밀로만 얻기로 했으므로 주지 않는다.
- 플레이어가 거래 목록에서 매달 지급을 직접 끊을 수 있다 = 우리가 어긴 것으로 처리.

## 6. 갈고리
- **우리가 쥐는 갈고리**: 첩보 보고서(알파 9 ②)가 확인된 비밀 — 우리를 칠 전쟁 명분(cb)·공격 계획·약화 계획·속국화 계획 — 을 담으면 그 제국에 갈고리 1개(제국마다 최대 1개, 쓸 때까지 유지). 거래판에서 「갈고리 쓰기」를 켜면 +30%p, 거래가 수락이든 거절이든 사라진다.
- **상대가 쥐는 갈고리**(우리가 약속을 어겼을 때): 그 AI 와 대화하면 프롬프트에 「우리가 약속을 어긴 일을 쥐고 있다」가 들어간다. 그 AI 가 대화에서 에너지를 요구(take_energy)했을 때 우리가 거절하면 호감 -30(수정자 sllm_deal_hook_refused 「빚을 외면함」)이 더해지고 갈고리가 사라진다.

## 7. 참전 요청
- **우리가 요청**: 우리가 전쟁 중일 때 거래판에 「참전」 항목(그 전쟁·우리 편). 방위 조약·연방 상대면 +25%p. 수락하면 모드가 `join_war = <우리>` 를 건다. 동맹 상대가 거절하면 신문 보도(동맹 의무를 저버렸다) + 우리 연대기.
- **AI 가 요청**: 방위 조약·연방 상대가 방어 전쟁에 들어갔는데 우리가 참전하지 않았으면 다음 달 알림 「X 가 참전을 요청합니다」(수락 / 거절). 거절하면 그 제국 호감 -30 + 신문 보도. 수락하면 `join_war`.

## 8. 게임 쪽 (4.5.1 덤프 확인)
- 읽기: `export_resource_stockpile_to_variable`·`export_resource_income_to_variable`(양쪽 창고·월수입), `relative_power = { category = all }`, `trust`, `is_rival`, `has_defensive_pact`, `is_in_federation_with`, `attacker_war_exhaustion`·`defender_war_exhaustion`(전쟁 범위), `is_war_participant`.
- 쓰기: `add_resource`(양쪽), 국경 개방(기존 open_borders 효과), `end_rivalry`, 종전(기존 평화 중재 연결), `join_war`, `add_opinion_modifier`(약속 파기 -50·참전 거절 -30 새 수정자).
- 요청 번호로 한 번만 처리(중복 방지), 결과는 게임이 다시 확인한 값만 믿는다.
