# SLLM 한 판 점검표 — 2026-11-08 작업분

새 게임 한 판(회랑의 삼파전 시나리오)으로 이번 작업을 한꺼번에 확인하기 위한 순서표입니다.
위에서부터 차례로 진행하면 됩니다. 각 항목에서 **[로그]**는 앱 로그(개발자 도구의 로그 창)에 나와야 하는 줄이고, **[화면]**은 눈으로 확인할 곳입니다.
안 되는 항목이 있으면 그 번호와 그때의 `error.log` 를 같이 보내 주세요.

- [ ] 런처에서 SLLM 본 모드(`sllm_missive`)와 시나리오 모드(`sllm_scenario_corridor`)가 켜져 있는지 확인합니다.
- [ ] 회랑의 삼파전 시나리오로 새 게임을 시작합니다.

## 2. 시작 화면과 영토

- [ ] **[화면]** 세 나라(얼라이언스·제국·플레이어) 영역의 빈 성계에 전초기지가 다 서 있는지(구멍 난 성계가 없는지).
- [ ] **[화면]** 지구(얼라이언스 수도)의 모습이 그대로이고 몰락 제국 건물이 올라가 있는지.
- [ ] **[로그]** `SLLM:SCNOWN` 줄이 들어오고, 앱의 제국 지도에 세 나라 땅이 칠해지는지.
- [ ] **[화면]** 제국 지도에 거점 성계 ◉ 표시가 보이는지(회랑 14곳: 이동로 7, 변경 7).

## 3. 사무실 창(전체 화면 · 창 겹침)

- [ ] 앱을 켜면 사무실 창이 **처음부터 전체 화면**으로 뜨는지(아래 작업 표시줄 자리까지 채움).
- [ ] **F11** 로 전체 화면을 끄고 켤 수 있는지.
- [ ] 귀족 접견 장소 고르기 창이 화면 가운데에 뜨고 클릭되는지(왼쪽 위로 사라지지 않는지).
- [ ] 메뉴 창도 가운데에 뜨고 다른 창보다 위에 보이는지.
- [ ] 묻는 창(이름 바꾸기·괴뢰 확인 등)이 앱 안 대화 상자로 뜨는지(브라우저 기본 알림창이 아님).

## 4. 나라 이름 바꾸기

- [ ] 회랑 귀족 창에서 **✎ 이름** 줄을 눌러 이름을 바꿉니다(예: 「OO」).
- [ ] **[화면]** 「회랑 직할」 → 「OO 직할」, 「회랑 귀족」 → 「OO 귀족」 식으로 탭·지도·안내 문구가 바뀌는지.
- [ ] 게임을 끄지 않아도 바로 바뀌는지, 앱을 다시 켜도 이름이 남아 있는지.
- [ ] 한국어/영어 전환 시 둘 다 자연스럽게 나오는지.

## 5. 바로 반영(매달 확인 대신 일이 생길 때 보내기)

- [ ] **[로그]** 매달 `SLLM:SCNTICK` 짧은 줄만 오고, 1년(12달)에 한 번 전체 보고가 오는지.
- [ ] 저장 → 불러오기 하면 **[로그]** 곧바로 소유 보고(`SCNOWN`)가 다시 오는지(불러오기 직후 지도 갱신).
- [ ] 위기 상태 줄(`SLLM:CRISIS`)은 **바뀔 때만** 오는지 — 위기가 없으면 매달 오지 않아야 함.
- [ ] 불러오기 직후에는 위기 상태 줄이 한 번 오는지.

## 6. 괴뢰·반란이 바로 지도에 보이는지

- [ ] 귀족 하나를 괴뢰로 세웁니다(괴뢰 확인 창 문구 확인).
- [ ] **[화면]** 1년을 기다리지 않고 제국 지도에 그 성계의 주인이 바로 바뀌는지.
- [ ] 반란이 일어나면(또는 콘솔로 일으키면) 반란 성계가 바로 지도에 반영되는지.

## 7. 수비대가 정복을 따라가는지

- [ ] 수비대가 있는 성계를 다른 나라가 차지하게 만듭니다(전쟁 점령·반란·괴뢰 등).
- [ ] **[화면]** 그 성계의 수비대 함대(정거장) 주인이 새 주인으로 바뀌는지(예전 주인 깃발로 남아 있지 않은지).
- [ ] **[로그]** `SLLM:SCNGAR … k=follow` 줄이 오는지.
- [ ] **[로그]** `SLLM:SCNGAR` 줄에 더 이상 `$S$` 같은 깨진 글자가 없는지.
- [ ] 수비대 함선 모습이 비어 있지 않은지(모델이 보이는지).

## 8. 거점 성계 섹터

- [ ] 거점 성계의 **지정된 행성**을 점령/식민했을 때만 그 거점이 우리 섹터로 잡히는지(다른 잠재 거주 행성으로는 잡히지 않아야 함).
- [ ] **[로그]** `SCNOWN` 줄의 `w=` 값이 거점 행성 주인 번호로 오는지.
- [ ] **[화면]** 거점을 다 차지하면 섹터 이름표가 그 거점 기준으로 묶이는지.

## 9. 대전략 카드

- [ ] 카드 그림 5장(전쟁 계획·함대 정찰·밀고·위조 문서·정상회담)이 모두 보이는지.
- [ ] **함대 정찰**: 쓰고 나면 **[로그]** `SCNFLTBEG` → `SCNFLT` 여러 줄 → `SCNFLTEND` 가 오고, 지도에 함대 배지(세력 크기)가 뜨는지. 180일이 지나면 흐려지거나 사라지는지.
- [ ] **정상회담**: 긴장이 높을 때 회담 제안이 생기고, 회담 장소(지정 성계 넷 중 하나)·날짜가 보이는지. 카드가 없을 때 「회담 없음」 사유가 나오는지. 회담 결과로 긴장이 내려가거나(성공) 올라가는지(결렬).
