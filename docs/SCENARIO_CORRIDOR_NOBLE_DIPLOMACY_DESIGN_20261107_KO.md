# 회랑의 삼파전 — 귀족 영역다툼 · 귀족 외교 · 반란 밀약 설계

작성: 2026-11-07
대상: 시나리오 「회랑의 삼파전」(sllm_scenario_corridor) · SLLM 앱 「제국 세력도」

## 0. 한 줄 요약

귀족 영지(앱 섹터, 보이지 않는 선)를 고정된 땅이 아닌 **영향력 싸움의 결과**로 만든다.
귀족들은 서로 **협약**을 맺고 깨며 땅을 다투고, 반란을 꾸미는 귀족은 미리 **밀약(약속)**을 모은다.
플레이어(군주)는 첩보·접견·하사로 판을 흔들고, 반란이 터지기 전에 연합을 쪼갠다.

게임 안은 여전히 **제국 하나**다. 영지 경계·호감도·협약·밀약은 모두 앱 안에서만 움직이고,
게임에는 **반란이 터지는 순간**에만 그 귀족(들)의 현재 영지 성계 목록을 넘긴다.

## 1. 원칙

- 영지가 왜 중요한가: **반란이 터지면 그 귀족의 영지가 통째로 반란국이 된다.** 영역다툼은 곧 "반란이 터질 때 얼마나 큰 나라가 떨어져 나가느냐"다.
- 속도는 연례 정보 회의(카드 시스템)와 맞춘다. 결과는 **연말 보고서**로 받는다. 매달 신호를 게임에 보내지 않는다.
- 즉시 알림은 무거운 사건만 보낸다: 밀고, 밀약 발각, 연합 반란, 협약 파기로 인한 전쟁 선포 수준의 일.
- 모든 화면 문구는 한글/영어를 함께 만든다. `L('한', 'En')` 그대로 써서 언어 팩과 호환되게 한다.

## 2. 단계

| 단계 | 내용 |
|---|---|
| 1단계 | 영향력 지도, 영역다툼(분쟁 성계 · 성계 넘어감), 귀족 간 호감도, 협약 3종(불가침·동맹·원한), 연례 귀족 판단, 지도·세력판 표시 |
| 2단계 | 반란 밀약(약속·조건·밀고·배신), 군주 충성 서약, 연합 반란(여러 귀족 영지를 한 반란국으로) |
| 3단계 | 혼인·봉신, 반란 뒤 약속 이행과 반란국 분열, 반란국 서류철 + 결속판(5.4) |

## 3. 1단계 — 영향력 지도와 영역다툼

### 3.1 영향력

성계 s 에 대한 귀족 n 의 영향력:

```
inf(n, s) = 힘(n) × 거리감쇠(hop(n의 거점, s)) × 보정
힘(n)     = 기본 10 + 영지 성계 수 × 0.6 + 성격 보정(야심 +3, 충동 +2, 신중 -1 …) + 충성 단계 보정(불만 이상 +2: 땅 욕심)
거리감쇠  = 0.75 ^ hop   (항로로 몇 칸 떨어졌는지)
보정      = 현재 주인이면 +25%(지키는 쪽이 유리) · 협약 상대의 성계면 0(불가침·동맹은 밀지 않음)
```

- 군주 직할(코어 섹터 2개)과 플레이어 성계는 다툼 대상이 아니다.
- 성계 주인 = 영향력 1등. 단, 1등과 현재 주인 차이가 **15% 이상**이고 그 상태가 **1년(연례 회의 한 번)** 이어져야 넘어간다. 그래서 국경이 잘게 떨리지 않는다.
- 1등과 2등 차이가 15% 안이면 **분쟁 성계**.

### 3.2 성계가 넘어갈 때

- 잃은 귀족: 빼앗은 귀족에 대한 호감 -15(성계 하나당, 최대 -45/년), 군주 충성 -3(군주가 막아 주지 않았다).
- 빼앗은 귀족: 힘이 커진다(위 공식). 영지가 처음 크기의 150%를 넘으면 다른 귀족들이 그 귀족에 대한 호감 -10(견제 심리).
- 거점 성계는 넘어가지 않는다. 귀족은 거점 하나만 남아도 살아 있다.
- 거점 말고는 땅을 모두 잃은 귀족은 「몰락」한다(2026-11-07 결정: **영구 사망 · 가문 소멸**).
  - 거점은 마지막 성계를 빼앗은 귀족에게 넘어간다.
  - 몰락한 귀족은 명단·세력판에 「몰락」으로 남는다. 초상은 흑백이고 다시 살아나지 않는다.
  - 그 귀족과 맺은 협약·밀약·서약은 모두 사라진다.
  - 동맹이었던 귀족들은 빼앗은 귀족에게 호감 -20.
  - 즉시 알림으로 알린다(무거운 사건).

### 3.3 귀족 간 호감도

- 귀족 두 명 사이마다 -100 ~ +100. 처음 값은 세력 갈래·성격·기존 인맥(bonds)에서 만든다.
- 해마다 0 쪽으로 20% 되돌아간다(기억이 흐려짐). 원한 협약은 되돌아가지 않는다.

| 원인 | 값 |
|---|---|
| 같은 세력 갈래 | +15 (계속) |
| 맞닿은 국경에 분쟁 성계 | 분쟁 하나당 -5/년 |
| 성계를 빼앗김 | 성계 하나당 -15 |
| 공동의 적(둘 다 원한을 둔 상대가 같음) | +20 |
| 성격 충돌(예: 명예 ↔ 계산) | -10 (계속) |
| 플레이어의 이간질 카드 | -25 |
| 플레이어의 중재(접견) | +20 |

### 3.4 협약

| 협약 | 맺는 조건 | 효과 | 깨지는 때 |
|---|---|---|---|
| 불가침 | 호감 +20 이상, 서로 맞닿음 | 서로의 성계를 밀지 않음 | 호감 -10 아래 · 한쪽이 상대 땅을 약속받음(2단계) |
| 동맹 | 호감 +45 이상, 공동의 적 또는 같은 갈래 | 서로 밀지 않음 + 공동의 적에게 힘 +20% | 호감 +15 아래 |
| 원한 | 호감 -50 아래 | 상대에게 힘 +25%, 협약 불가 | 플레이어 중재로 -20 위로 올라오면 풀림 |

- 협약을 깨면 깬 쪽이 다른 모든 귀족에게 신뢰 -10을 잃는다.

### 3.5 연례 귀족 판단 (연례 정보 회의 때 한 번)

순서:

1. 호감도 자연 회복과 국경 분쟁 반영
2. 영향력 다시 계산 → 성계 넘어감 처리
3. 귀족마다 협약 판단: 조건을 만족하면 제안하고, 상대가 조건을 만족하면 성사. 깨질 조건이면 파기
4. 너무 커진 귀족(영지가 전체 귀족 평균의 2배 이상)이 있으면, 그와 맞닿은 귀족들 사이에 견제 동맹을 우선 제안
5. 결과를 연말 보고서 「귀족 정세」 항목에 기록

연말 보고서 예:

- 「브뤼크너 가가 바이스그룬트·호엔펠스를 차지했습니다 (라이헤나우 가에게서).」
- 「바이스바흐 가와 라이헤나우 가가 동맹을 맺었습니다. 공동의 적: 브뤼크너 가.」
- 「오스터만 가가 아이젠바흐 가와의 불가침을 깼습니다.」

### 3.6 플레이어 개입 (1단계)

- **첩보 카드**
  - 기존 「이간질(sow)」: 대상 둘의 호감 -25
  - 새 카드 「국경 획정」: 분쟁 성계 하나를 현재 주인 쪽으로 1년간 고정
- **접견:** 「중재」 선택지. 두 귀족의 호감 +20, 원한을 풀 수 있음. 다만 중재받은 쪽 중 손해 본 귀족의 충성 -2.
- **군주 하사(직접 명령):** 1년에 한 번, 분쟁 성계 하나를 원하는 귀족에게 준다.
  - 받은 귀족: 충성 +8
  - 빼앗긴 귀족: 충성 -10, 하사받은 귀족에게 호감 -20

## 4. 2단계 — 반란 밀약

### 4.1 밀약을 모은다

- 충성이 「불만」 이상인 귀족 중 힘이 가장 큰 귀족이 **주모자**가 될 수 있다. 연례 판단 때 확률로 결정하며, 이미 반란 직전 단계면 확정.
- 주모자는 해마다 호감 +20 이상인 귀족에게 약속을 청한다. 대가로 무엇을 내거는지가 성사 확률을 정한다.

| 약속 대가 | 뜻 | 성사 보정 |
|---|---|---|
| 땅 | 이기면 제3 귀족·직할령의 성계 ○○을 준다 | 그 땅을 노리던 귀족이면 +30% |
| 지위 | 새 나라에서 2인자 | 야심 성격 +20% |
| 원한 | 함께 △△ 가문을 친다 | △△에게 원한이 있으면 +35% |

- 밀약은 숨겨져 있다. 첩보로 하나씩 드러난다(세력판에 점선 → 실선).

### 4.2 반란의 순간

주모자는 다음을 넘으면 일어난다.

```
밀약 힘 합 ≥ 군주 직할 힘 × 0.6
```

또는 최후통첩을 거절당해 막다른 길에 몰렸을 때 일어난다.

약속한 귀족마다 그 순간 다시 판단한다.

```
따를 확률 = 50% + (주모자 호감 - 군주 충성 점수)/2 + 혼인·동맹 +20% - 두려움(군주 군사력 우세) - 밀약 발각 시 20%
```

- 따르면 그 귀족의 영지도 반란국에 합쳐진다(**연합 반란**).
- 따르지 않으면 주모자에게 원한이 생긴다.
- **밀고:** 해마다 약속한 귀족 중 두려움이 큰 귀족이 낮은 확률로 군주에게 털어놓는다.
  - 플레이어는 즉시 알림을 받는다.
  - 그 밀약은 드러나고, 밀고한 귀족의 충성 +5.

### 4.3 충성 서약 (군주 쪽 약속)

- 접견에서 귀족에게 서약을 받는다. 충성 「평온」 이상이면 쉽게, 「불만」이면 대가(에너지·하사)가 필요하다.
- 서약과 밀약을 둘 다 한 귀족은 반란 때 하나를 깨야 한다.
  - 서약을 깨면: 다른 귀족들의 군주 신뢰는 그대로, 그 귀족은 반역자 낙인
  - 밀약을 깨면: 주모자와 그 동맹들에게 원한
- 서약을 깬 귀족에게 플레이어는 연설·처분 선택지를 얻는다(3단계에서 확장).

### 4.4 게임 쪽 반영

- 반란 효과 `sllm_cr_revolt` 는 지금 게임 섹터 표식(sllm_cr_mid)으로 성계를 고른다.
- 이것을 **앱이 성계 목록을 넘기는 방식**으로 바꾼다. 앱이 콘솔로 반란국에 넘길 성계마다 표식을 단 뒤, 하나의 반란 효과를 부른다.
- 연합 반란이면 여러 귀족의 성계를 한 반란국으로 넘긴다.
  - 수장은 주모자다.
  - 함께한 귀족들은 반란국 지도자 명단(총독·장군 등)에 올린다.

## 5. 화면

### 5.1 제국 세력지도 (첫 화면)

- 분쟁 성계는 두 귀족 색이 번갈아 깜빡이는 이중 테두리로 보인다.
- 「압력」 보기를 켜면 미는 쪽에서 밀리는 쪽으로 향하는 화살표를 그린다(국경 따라 짧은 화살촉).
- 색 보기에 「동맹 블록」을 추가한다. 협약으로 묶인 귀족들을 같은 계열 색으로 칠한다.
- 연말 보고서 뒤 처음 열면 **올해 국경 변화 되감기**(작년 경계 → 올해 경계 3초 재생)를 보여 준다. 다시 보기 단추도 둔다.

### 5.2 세력판 (두 번째 화면) → 외교판

- 귀족 사이의 선은 협약 종류로 그린다.
  - 불가침: 회색 실선
  - 동맹: 하늘색 굵은 선
  - 원한: 붉은 톱니선
  - 밀약: 주황 점선. 드러난 것만 보이며, 주모자 쪽에 화살촉.
  - 서약: 금색 선(군주와 귀족 사이)
- 귀족 상세 패널에 「관계」 탭을 둔다. 호감도 목록과 그 이유(최근 사건)를 보여 준다.

### 5.3 인물 관계도

기존 그대로 둔다. 협약 선은 외교판에서만 그린다.

### 5.4 반란국 화면 — 서류철 + 결속판 (2026-11-07 결정, 3단계)

반란국은 게임 속 진짜 나라(적국)다. 그래서 제국 안처럼 영지 경계를 칠하지 않고 다르게 그린다.

- **처음: 적국 첩보 서류철**
  - 반란국마다 서류철 하나가 생긴다. 안쪽은 사진 판에 붉은 실로 잇는 수사판 모양이다.
  - 첩보로 알아낸 만큼만 보인다. 모르는 귀족 칸은 「기밀」 띠로 가려지고, 관계 실은 끊어진 점선이다.
  - 그 반란국을 다시 쪼개는 공작(이간질·약속 위조 등)의 무대가 된다.
- **정보가 쌓이면: 결속판**
  - 서류철이 일정 이상 드러나면(예: 함께한 귀족의 절반 이상 신원 파악) 결속판이 열린다.
  - 반란국을 원형 회의 탁자처럼 그린다. 주모자가 가운데, 함께 일어난 귀족들이 둘레에 앉는다.
  - 자리마다 「약속받은 것 / 실제로 받은 것」과 불만 게이지가 붙는다.
  - 불만이 넘치면 그 자리가 금 가며 갈라진다. 반란국 내분, 2차 독립, 또는 제국으로의 귀순으로 이어진다.
- **연결:** 세력지도에서 반란국 땅을 누르면 이 화면이 열린다. 반란국 땅 자체는 그 나라 색으로만 칠한다.

## 6. 자료 (세이브별 JSON에 추가)

```ts
interface NobleRel { a: number; b: number; op: number; why: { t: string; v: number; y: number }[] } // 호감도와 최근 이유
interface Pact { a: number; b: number; k: 'nap' | 'ally' | 'feud'; since: string }
interface Pledge { lead: number; who: number; price: { k: 'land' | 'rank' | 'feud'; sys?: number; tgt?: number }; since: string; seen: boolean }
interface Oath { who: number; since: string; cost?: number }
interface DomainState {
  owner: Record<number, number>;   // 성계 id → 귀족 id(직할은 -1, -2)
  pend: Record<number, { by: number; y: number }>; // 넘어갈 예정(1년 유지 확인용)
  lock: Record<number, number>;    // 국경 획정 카드로 고정된 성계 → 풀리는 해
  history: { y: number; changes: [number, number, number][] }[]; // [성계, 전 주인, 새 주인] — 되감기용
}
```

- 처음 영지는 지금의 정적 섹터(staticBook)에서 만든다.
- 게임 소유권이 바뀐 성계(전쟁·반란)는 그쪽이 우선이다. 제국 밖으로 나간 성계는 영지에서 빠진다.
