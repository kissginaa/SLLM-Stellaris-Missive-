# 모드 초상화 불러오기 설계 (2026-10-26 초안, 설계만 — 구현은 집 PC에서)

앱이 켜진 모드의 초상화 파일(모델·텍스처)을 직접 조립해 그림으로 만들고, 바닐라 포트레이트 라이브러리처럼 쓴다.
상태: 사용자 결정 2026-10-26 "일단 설계로만 두자". 코드 없음.

## 1. 배경
- 2026-10-17 포트레이트 라이브러리: 게임 `.mesh`/`.dds` 를 블렌더 없이 직접 그려 바닐라 299종(WebP 565장)을 만들어 `portrait-library.pak` 으로 넣음. **그린 결과만 앱에 있고, 그린 도구(렌더러)는 남아 있지 않음**(작업컴·클라우드 작업 폴더 확인 2026-10-26). 집 PC에 남아 있는지 먼저 찾아볼 것.
- 앱에 남은 옛 방식 `docs/portraits_unused_reference.ts`(텍스처에서 가장 큰 덩어리만 잘라냄)는 사람형이 대머리 맨몸이 되어 쓰지 않음.
- 지금은 모드 종족이면 라이브러리에 없어 기본 계열 그림이나 사용자가 올린 그림을 씀.

## 2. 흐름
1. **필요한 것만**: 세이브 `species_db` 의 초상화 키(`portrait=`) 중 라이브러리에 없는 키만 고른다(세이브가 정확한 키를 주므로 추측 불필요).
2. **켜진 모드에서 찾기**: 런처 `dlc_load.json` 의 켜진 모드 → `.mod` 기술 파일의 path/remote_file_id → 모드 폴더(문서\mod, 창작마당 `steamapps/workshop/content/281990/<id>`). 각 모드의 `gfx/portraits/portraits/*.txt`(portraits·portrait_groups) 와 `gfx/models/portraits/**` 를 읽는다. **읽기만** 한다(구독 폴더 쓰기 금지 규칙).
3. **조립·그리기**: 몸·옷·머리·장식 파츠를 정의대로 조립 → 기본 자세 한 장을 소프트웨어 래스터라이저로 그림 → 4:5 액자 WebP.
4. **캐시**: 앱 데이터 `portrait_library_mods/<모드id>/<키>.webp` + 목록 json. 모드 파일의 크기·수정 시각이 같으면 다시 그리지 않음.
5. **쓰기**: 기존 라이브러리와 같은 경로로 — 대화 상대 자동 선택, 의회 의원 얼굴, 설정 > 초상화 목록(「모드」 묶음 추가). 사용자가 올린 그림이 있으면 그것이 먼저(지금 규칙 그대로).
6. **화면**: 설정 > 초상화에 「모드 초상화 불러오기」 단추 + 진행 표시(n/m) + 결과(성공·실패 개수, 실패한 키 목록). 세이브를 열 때 자동으로도 할지 설정(기본 켜짐 제안). 한/영 문구, 언어 팩 규칙 준수.

## 4. 한계·위험
- 2D 그림형 초상화(texturefile 하나)는 쉬움. 특수 셰이더(빛남·종족 색 팔레트·마스크), 애니메이션 전용 파츠는 비슷하게만 나올 수 있음. 움직임 없음(한 장).
- 모드가 바닐라 파일을 덮어쓰는 경우(초상화 교체 모드) → 바닐라 키도 모드 쪽 그림이 우선이 되게 할지 결정 필요(제안: 설정에 「모드가 바꾼 바닐라 초상화도 다시 그리기」 선택).
- 큰 모드 팩은 파일이 많아 첫 실행이 오래 걸릴 수 있음 → 세이브에 있는 종족만 그려서 줄임.
- 배포 문제 없음: 사용자 PC 의 파일을 그 PC 에서만 그리고 다시 배포하지 않음.

## 5. 순서 (집 PC — 게임·모드 파일 필요)
1. 렌더러를 다시 만들고(또는 남아 있으면 찾아서) **바닐라 299종을 그려 기존 라이브러리와 비교** → 같게 나오면 통과.
2. 모드 스캔 + 세이브에 있는 모드 종족만 그리기 + 캐시.
3. 화면·설정·한/영.
4. 인기 초상화 모드 몇 개로 시험(실패 키 목록 확인).
