# 「회랑의 삼파전」 메인 메뉴·로고·로딩 화면 그림 의뢰서 — 2026-11-06

시나리오 모드를 켜면 스텔라리스 첫 화면부터 이 시나리오의 분위기가 나도록 하는 그림입니다. 모두 14장입니다.
화풍은 지금까지의 행성·초상 그림과 같은 반실사 SF 디지털 페인팅으로 맞춰 주세요.

## 공통 규칙
- 실존 인물, 실제 정치 상징(국기·하켄크로이츠·SS 룬·독수리 문장 등), 실존 제복을 넣지 않습니다.
- 세력 문장은 가상 문장만 씁니다.
  - 얼라이언스: 금빛 월계관 + 행성
  - 제국: 톱니바퀴 안의 팔각 별
- 로고 말고는 글자를 넣지 않습니다.

## 세계관 요약 (그림 참고용)
- **은하 얼라이언스**: 수도는 지구입니다. 하늘색·흰색·금색을 쓰고, 인류와 여러 외계 종족이 함께하는 민주 연방입니다.
- **인류 제국**: 수도는 데네브의 「철의 행성」입니다. 검정·핏빛 빨강·무쇠색을 쓰고, 인류 순혈주의 군사 독재입니다.
- **회랑**: 두 열강 사이 좁은 성계 띠입니다. 작은 나라(플레이어)가 끼어 있습니다.
- 시작은 전쟁 직전, 긴장감이 팽팽한 순간입니다.

## 1. 메인 메뉴 배경 — `sllm_cr_menu_bg.png`
- 2560 × 1440 PNG(RGB)입니다. 게임이 화면 크기에 맞춰 늘립니다.
- 장면: 우주에서 내려다본 회랑입니다. 왼쪽 멀리 푸른 지구와 하늘색 함대, 오른쪽 멀리 검붉은 철의 행성과 붉은 함대가 있고, 가운데 성운 띠(회랑) 사이로 작은 정거장 하나가 빛납니다.
- **왼쪽 ⅓은 메뉴 버튼이 올라가므로** 어둡고 단순하게 그려 주세요. 시선은 가운데에서 오른쪽에 모이게 합니다.

## 2. 게임 로고 — `sllm_cr_logo.png`
- 1800 × 340 PNG, 투명 배경(RGBA)입니다. 게임에는 900 × 170으로 줄여 넣습니다.
- 글자는 큰 제목 `THE CORRIDOR TRIANGLE` 한 줄과, 그 위 작은 글씨 `SLLM SCENARIO`입니다. 철자를 정확히 지켜 주세요.
- 스텔라리스 원래 로고처럼 은빛 금속 글자에 은은한 빛을 줍니다. 왼쪽 끝에 두 세력 문장이 맞물린 작은 엠블럼(월계관과 톱니바퀴가 반씩)을 둡니다.
- 가장자리를 투명하게 깔끔히 처리해 주세요.
